# Name corpus

The PR descriptions of the series quote a corpus of 143,785 real names
(field-collected DoH samples plus a stratified Tranco slice) used for
spill-rate accounting, allocation counts and the behavior differentials
between `main` and each branch.

That corpus was not available in the session that produced this
directory, so it is not included. When it is added, put it here as one
name per line (presentation format, trailing dot for FQDNs) together
with a note on how it was collected and any filtering applied, so the
numbers in the PRs can be reproduced from the tree.
